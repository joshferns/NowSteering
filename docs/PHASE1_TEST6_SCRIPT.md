# Phase 1 test 6: build 0.2.19 (~2 min parked + one normal navigated drive)

**At home:** install NowSteering.apk; check the version is **0.2.19** (Settings → Apps → Now Steering).
Turn **Power saving OFF**. Open Now Steering: the top box must say **Setup complete**. Diagnostics → **Clear**.

## Parked (one action per step)
1. Start the car; wait for "Now Steering is on".
2. Turn **Power saving ON**. Note: does the car show "Power saving on / nav less smooth" for ~6 s?
3. Turn **Power saving OFF** again.
4. Start Google Maps navigation to a known place with a few turns. Note: does the first instruction appear within ~3 s, without flicking between roads?
5. Lock the phone.

## Drive (phone locked, glance only)
6. On each approach to a turn, note: is the distance ever smaller than Google Maps' own (if a passenger can compare)?
7. Note: does the bottom line show the turn arrow + bar (e.g. `→ █████▒▒▒▒▒`)?
8. If Maps reroutes, note: does the car keep the previous instruction until the new one appears (no `•`)?
9. On arrival, note: does `● Arrived` appear as Maps shows its destination marker (not ~1 min later)?
10. Park and stop for a moment. Note: does `● Arrived` stay?
11. Drive off. Note: does it switch to the clock when you move away?
