# Phase 1 test 5: build 0.2.18 (~4 min parked + one normal navigated drive)

**At home:** install NowSteering.apk and check the version is **0.2.18**
(Settings → Apps → Now Steering). Diagnostics → **Clear**.

## Parked: bar width test (one action per step)
1. Start the car; wait for "Now Steering is on".
2. Open **Diagnostics**. In the text tester, Album: pick preset **Turn bar (10 cells)**.
3. Tap **Show on car**. Note: are all 10 blocks visible? 📷
4. Album: pick **Trip bar line**. Tap **Show on car**. Note: is "ETA 09:45 ███▒▒" complete? 📷
5. Album: pick **Trip bar line 12h**. Tap **Show on car**. Note: complete?
6. Album: pick **18 full blocks**. Tap **Show on car**. Note: how many blocks are visible? 📷
7. Tap **Back to live**.

## Parked: music re-claim when NOT navigating
8. Start YouTube Music playing.
9. Press steering **Next** once. Note: after the song changes, does the car keep showing the song (not "Now Steering")?

## Drive (Power saving ON, phone locked, glance only)
10. Turn **Power saving ON**.
11. Start Google Maps navigation to a known place with a few turns; lock the phone.
12. Drive. Before each turn, note: does the bottom line become a bar that fills up, and go back to "ETA … ███▒▒" after the turn?
13. Once, mid-route: press steering **Next**. Note: ~2 s after the song changes, is the nav screen back?
14. Note: does the distance ever jump up?
15. On arrival, note: does `● Arrived` stay until you drive off or double-tap **Next**?
16. Turn **Power saving OFF** (or leave it, if nav was fine).
