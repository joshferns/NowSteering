# Phase 1 test 3 (~5 min parked + a normal short drive)

**At home:** install the new NowSteering.apk. The top box must say **Setup complete**. A new line checks
**Power saving OFF**: if it says MISSING, turn off Power saving (quick settings, or Settings → Battery). Diagnostics → **Clear**.

## Parked
1. Start the car; wait for "Now Steering is on".
2. Lock the phone. Watch the car 10 s. Note: does the speed stay `0 km/h` (not `-- km/h`)?
3. Unlock. Start Google Maps navigation to a known place 1–3 km away with at least two turns.
4. Note: does the car show a real arrow (↑ ← →), not `•`? 📷

## Drive (phone locked the whole way, glance only)
5. At each turn, note: was the arrow right? Did the distance count down smoothly to the turn?
6. Note anything wrong, stale or stuck, and roughly where.
7. On arrival, note: does the car show `● Arrived` / place name for ~10 s, then the clock with speed?

## After
8. Diagnostics → **Share file**, send it with your notes.

**Notes template**
```
2: speed with phone locked: …   4: arrow shown: …
5: (per turn) arrow right? countdown smooth? …
7: …   odd: …
```
