# Last two checks (v0.3.3)

Rules: glance only while driving, no phone use, no voice dictation, no photos while driving.

**Before (parked)**
- Start YouTube Music playing, and start Google Maps navigation to a place about 3 km away.
- Tick **Keep Now Steering on screen** (for step 2, it does no harm for step 1).
- Diagnostics → type `Final check start` → **Add note**.

1. **Next while navigating** (Drive 1 step 8). On a safe road, press steering **Next** once, at least 5 s into a song.
   Expect: the song changes, and the nav screen is back on the car within about 3 s.
2. **Previous with Keep on.** Later in the same drive, with YouTube Music still playing at least 5 s into a song, press steering **Previous** once.
   Expect: the song restarts or goes to the previous one. Note which, or "nothing".

**Parked**
- Diagnostics → type `Final check end` → **Add note**, then **Share key lines**. Send it with your notes.

```
1: song changed? nav back in ~3 s?   2: restarted / previous / nothing
```
